Summary method

Off by default. When off, a script on this PC makes an extractive summary from the original text. No external AI is used and this summary feature consumes no AI credits.

When on, GitHub Copilot is used. The title, body and facts of the selected memory are sent only when you press the summarize button in the detail pane, confirm, and choose a model. Switching this on sends nothing. The original memory is not changed.

When on, you must be signed in to Copilot. Some models consume usage quota. Terms of use and data handling follow your plan and your organization's policies.
